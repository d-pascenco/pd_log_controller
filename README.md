## Разработка системы предиктивного обнаружения аномалий в логах ПО с использованием методов МО

Вход: логи приложения / сервиса.
Выход: вероятность аномального состояния или будущего инцидента.
ML-задача: anomaly detection / binary classification / time-series prediction.
Практический результат: dashboard + API + алерты.

### Стек, компоненты, запчасти:

- **Host:** Oracle Free Tier
- **OS:** Linux Oracle
- **Backend:** FastAPI
- **Frontend:** Streamlit
- **База данных:** PostgreSQL
- **Репозиторий:** GitHub
